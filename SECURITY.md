# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability, exposed credential, or sensitive captured content. Use GitHub's private vulnerability reporting for this repository. If that surface is unavailable, contact the repository owner privately through the contact information on their GitHub profile.

Include the affected version or commit, impact, minimum reproduction, and a suggested mitigation when known. Never include a reusable secret or private customer capture.

## Supported version

Screenwalk is pre-1.0 public beta software. Security fixes target the latest commit on the default branch; older commits are not supported.
